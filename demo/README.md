# WordTemplateBundle — demo

Demo application is **not** shipped in the Composer package (`archive.exclude` includes `/demo`). Clone this repository to run it.

## Symfony 8 (`demo/symfony8`)

FrankenPHP + Docker Compose (Symfony **8**, PHP **8.2**). Default port **8021**.

```bash
cd demo/symfony8
cp .env.example .env
make up
```

Open the printed URL. The form discovers placeholders in **`public/demo/doc-final-tpl.docx`** via `listVariables()` and exercises:

| Feature | Demo control |
|---------|----------------|
| Scalars / dot keys | Text fields (`chapter.number`, `author1.name`, …) |
| Inline word A or B | VIP checkbox → `${client_tier_label}` |
| `HtmlContent` | HTML textareas (`abstract`, `*.body`, …) |
| `TableRows` | Repeating row tables (`row_code`, `ref_text`) |
| `ConditionalBlock` | Checkboxes for `optional_funding` |
| Nested conditional | `funding_detail` inside `optional_funding` |
| `ImageSource` | Path field for `${demo_logo}` |

Downloads:

- **Download blank template** — original `.docx` with `${…}` placeholders unchanged (`GET /template`).
- **Download .docx** — filled document from the form (`doc-final-tpl-filled.docx`).
- **Download PDF** — same content via PhpWord + DomPDF (fidelity limits noted in the UI).

Default `HtmlContent` values include inline-styled HTML tables (borders and background colours) as a PHPWord styling reference.

### Conditionals (`/conditionals`)

Navbar link **Conditionals**. One form field per PHP type (`bool` checkbox, `?bool` choice, `?int`, `?float`, `string`, `?string`, backed enum, date, order lines as an array, free-string plan) — the controller turns each value into `ConditionalBlock`s with the expressions documented in [docs/USAGE.md — Conditionals by data type](../docs/USAGE.md#conditionals-by-data-type) (`App\Conditionals\ConditionalsContextBuilder`).

- **Preview decisions** — table of value → expression → blocks kept (green) / removed (grey), and a second table with the **expression conditionals** of the template (`${#if order.total > 100}` … `${#endif}`, evaluated by the bundle from the raw `order` values; the demo sets `conditional_expressions.enabled: true`).
- **Download .docx** — merges `public/demo/conditionals-tpl.docx` (header `draft` block, "else" pairs, enum and free-string "one of N", a table shown only when there are order lines).
- **Download the blank template** — `GET /conditionals/template`.

The template is generated by `php bin/build-conditionals-template.php` (inside the container); re-run it after editing the script.

### Expression examples (`/conditionals/examples`)

Navbar link **Expression examples**. One card per case (`App\Conditionals\ExpressionExamples`): named block, expression true / false, functions, nested blocks, "else" pair, one of N, a table only when there are rows (with and without rows), dates with `now()` / `date()`, and an error (unknown variable). Each card shows the text typed in Word, the PHP context and the generated document text, with **template .docx** and **generated .docx** downloads (`GET /conditionals/examples/{id}/template.docx|result.docx`).

### Playwright e2e and screenshots (REQ-DEMO-013)

```bash
make -C demo/symfony8 test-e2e          # e2e in the official Playwright image
make -C demo/symfony8 demo-screenshots  # docs/images/demo/{home,conditionals,expression-examples}.webp
make -C demo/symfony8 docx-previews     # docs/images/demo/docx-*.webp: template in Word → generated document
```

`docx-previews` exports every example with `bin/console app:conditionals:export-examples`, renders both `.docx` files with LibreOffice (`LIBREOFFICE_IMAGE`, default `debian:bookworm-slim` with LibreOffice installed on the fly; any image that already has `soffice` is used as is) and composes the side-by-side images with `e2e/scripts/docx-side-by-side.mjs`.

The bundle source is mounted at **`/var/word-template-bundle`** (see `docker-compose.yml`).

See [docs/DEMO-FRANKENPHP.md](../docs/DEMO-FRANKENPHP.md) for architecture (Caddyfiles, DNS for Composer, etc.).
